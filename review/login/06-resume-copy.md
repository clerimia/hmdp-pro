# 登录模块简历描述

## 推荐版

负责校园餐饮评价平台手机号验证码登录、会话鉴权及退出接口的开发与测试。针对原链路存在重复发码覆盖验证码、验证码可重复使用、错码无锁定及登录态过长等风险，使用 Redis `SET NX EX` 实现 60 秒发码幂等冷却，通过 Lua 脚本原子完成验证码校验、一次性消费、错误计数及 5 次失败锁定 5 分钟，并基于 Redis Hash 实现 30 分钟滑动续期和幂等退出；使用 Python + pytest 设计并落地 23 条接口自动化用例，覆盖参数边界、自动注册、鉴权、会话生命周期及 Redis 故障降级，采用状态注入、条件轮询和 HTTP/Redis/MySQL 跨层断言完成缺陷闭环，登录套件 23/23、项目 pytest 回归 50/50 通过。

## 简历空间较小时

负责手机号验证码登录、Redis 会话鉴权与退出接口开发；使用 Redis `SET NX EX` 和 Lua 原子脚本实现发码幂等冷却、验证码一次性消费及错码锁定，完成 30 分钟滑动会话与幂等退出；借助AI辅助基于 Python + pytest 建设 23 条接口自动化用例，通过状态注入及 HTTP/Redis/MySQL 跨层断言覆盖登录安全、会话生命周期和 Redis 故障降级，回归通过率 100%。

## STAR 对应关系

- **S（背景）**：教学项目登录主流程可用，但存在验证码可复用、无频控、无锁定、会话过长和退出缺失。
- **T（任务）**：负责登录、鉴权和退出接口改造，并建立可重复执行的登录链路自动化回归。
- **A（行动）**：Redis 滑动窗口限流；Lua 原子验证码状态机；Redis Hash 滑动会话；pytest 状态注入、条件轮询和跨存储断言。
- **R（结果）**：修复四类安全与协议问题，落地 23 条登录用例，登录 23/23、pytest 全量 50/50 通过。

## 使用提醒

- 简历建议使用“推荐版”或“简历空间较小时”二选一，不要同时放。
- “回归通过率 100%”必须和测试报告一起保留证据；当前证据是 `autotest/reports/login-report.html`。
- 面试展开时优先讲“验证码可复用 → 失败测试 → Lua 原子消费”以及“缺参 400 被 `/error` 鉴权覆盖成 401”两个真实缺陷闭环。
